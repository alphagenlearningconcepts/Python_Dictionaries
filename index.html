Dictionary Functions

Adding, Modifying & Deleting Items

1

Add New Item

Assign a value to a new key name:

student["school"] = "Alphagen"
Inserts new key-value pair!
2

Change Value

Assign a new value to an existing key:

student["marks"] = 98
Overwrites previous value!
3

Remove Item

Use del or .pop():

del student["age"]
Removes key and its value!
Remember: Keys must be unique! Assigning a new value to an existing key updates it instead of creating a duplicate.
